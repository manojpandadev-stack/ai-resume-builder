# AI Resume Builder

An Enterprise AI Resume Builder built with Spring Boot, React, JWT Authentication, Groq LLM API, and MySQL.

## Features

- AI-powered resume generation
- JWT Authentication
- User Management
- Resume PDF Generation
- REST APIs
- Swagger Documentation
- Docker Support
- Unit & Integration Testing

## Tech Stack

- Java 21
- Spring Boot 3
- Spring Security
- JWT
- Spring AI
- Groq API
- React
- MySQL
- Maven
- Docker
- JUnit 5
- Mockito
- GitHub Actions

## Running the Project

1. Clone the repository

```
git clone https://github.com/manojpandadev-stack/ai-resume-builder.git
```

2. Configure your database.

3. Add your Groq API Key.

4. Run

```
mvn spring-boot:run
```
